# Working preferences

Prefer relevant skills, APIs, connectors, and CLI tools when they simplify or speed up the work. Avoid redundant calls and checks. Use the website directly when its interface is more efficient, such as filling in forms.

# Language

Write new or modified project content in English, including documentation, specifications, code comments, and user-facing text. Translate existing content when it is part of the requested work; leave unrelated files unchanged. Match the user's language in conversation.
