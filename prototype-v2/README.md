# Meeting Record · React prototype

From this directory, run `npm ci` and `npm run dev`. Open the URL printed by Vite. Run `npm run build` for a static build in `dist/`.

Home shows recent meetings and recording totals. Labels can be created, edited, assigned to meetings, and used to filter the library. Settings controls the sample microphone, model, and visibility of transcript timestamps.

Recording, playback, and assistant replies use sample data. Meetings, labels, and preferences reset when the page reloads.
